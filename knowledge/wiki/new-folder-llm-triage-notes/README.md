# New folder:LLM triage notes

This is a Team Wiki Notebook. It tracks work items, observations,
decisions, and evidence for a collaborative investigation.

## Structure

- **INBOX.md** -- Scratchpad for quick updates. The triage agent
  periodically promotes items to the appropriate pages.
- **overview.md** -- Derived, triaged summary of current understanding.

## Contributing

Add new observations, links, or experiment notes to the INBOX.md
file (root-level or inside a work instance). Use the contribution
format:

```
___
**Contributed by:** Your Name
**Contributed on:** YYYY-MM-DD

**Contribution:**
Your observation or update here.
```
